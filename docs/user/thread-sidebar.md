# Organizing tasks

Pin a task from its context menu to keep it in the pinned section above your active work.
Pinned tasks are shown independently of their workspace, including when you connect to more than
one environment.

Drag a pinned task to change its position. The order is stored by the server and appears on your
other connected devices.

If reordering is unavailable for one environment, update the Janus server running in that
environment. Older servers can still pin and unpin tasks, but do not understand synced ordering;
their pinned tasks keep the default newest-first order below the ones you have arranged.
