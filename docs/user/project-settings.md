# Customize a workspace icon

Janus selects a workspace icon automatically. It checks `t3.json`, common favicon and app icon
paths, and icon links in the workspace's HTML files.

To choose a different icon:

1. Open the workspace's settings: hover the workspace in the sidebar and select **Workspace settings**, or open the Command Palette and choose **Workspace settings**.
2. On the **Project icon** row, select **Choose file**.
3. Search for an image file and select it.

Janus supports SVG, PNG, ICO, JPEG, GIF, AVIF, and WebP files. The selected path applies to
each checkout in the workspace and appears on your connected devices.

To use automatic detection again, use the reset control on the **Project icon** row. The row shows
**Automatic** when no custom icon is set.
